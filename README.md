# Hunter 350 Zip-Tie Traction Strap

A 3D-printable, zip-tie style anti-skid snow traction strap sized for the Royal Enfield Hunter 350.

The project page (interactive 3D viewer, 360° video, reference photos and specs) is in [`docs/`](docs/) and is served by GitHub Pages.

The strap has not been printed or load-tested.
